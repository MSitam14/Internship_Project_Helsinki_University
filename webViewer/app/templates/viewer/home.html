Molecular Structure Analysis Platform

A web platform for the analysis, visualization, and comparison of molecular structures.

This project provides an accessible interface for computational tools developed for the analysis of molecular environments and structural properties.

Project Context

Understanding the structural and chemical properties of biological molecules is an important part of modern drug discovery. Computational methods make it possible to analyse molecular structures and identify relevant features that may contribute to molecular recognition and ligand binding.

This project was developed to provide a simple and accessible web interface for computational methods that would otherwise require direct use of scientific scripts and specialised molecular visualisation software.

Available Tools
Fitness Score

Analyse a molecular structure and calculate fitness scores for individual atoms and for the overall system.

Hotspot Analysis

Identify and analyse regions of interest within molecular structures.

Structural Comparison

Compare molecular structures and identify similarities and differences between their chemical environments.

How It Works
1. Upload

Upload one or more molecular structure files.

2. Configure

Select the parameters required for the analysis.

3. Analyse

Run the computational analysis and visualise the generated results.

Result Visualisation

The results generated by the computational methods can be explored directly through the web interface.

Molecular structures and analysis results are displayed using interactive three-dimensional visualisation tools, making it easier to explore structural features and interpret the calculated data.

Research Context

This project was carried out within the Computational Drug Discovery Group at the University of Helsinki.

The group develops computational approaches for drug discovery, combining chemoinformatics, molecular modelling, structural analysis, and computational tools to support pharmaceutical research.

Project Objective

The main objective of this project is to make specialised computational tools easier to access and use.

By combining existing scientific methods with a modern web interface, the platform aims to reduce the need for direct interaction with command-line tools while providing clear visualisation and downloadable results.
