
# Atomic Fitness Score and Contact Preferences

<p style='text-align: justify;'>
This project provides a script that evaluates positional atomic fitness and molecular contact preferences within molecular environments. It calculates an atomic fitness score by comparing the distance densities distribution of a given atom to the average for that atom type in the training set. Additionally, it assesses molecular contact preferences by comparing frequencies of contacts for the atom within its molecular environment against the training set averages.
</p>

## Installation

### Prerequisites

You will need [Python 3.9](https://www.python.org/downloads/) and [Conda](https://docs.conda.io/projects/conda/en/latest/user-guide/install/) installed on your machine. You can optionally use [pip](https://pip.pypa.io/en/stable/installation/) instead of Conda.

### Using Conda Environment (Recommended)

Clone the repository and navigate to the project directory. 

Create a Conda environment using the [`environment_conda.yml`](env/environment_conda.yml) file with the following command:

```bash
conda env create -f Fitness_score/env/environment_conda.yml
```

Activate the Conda environment:

```bash
conda activate Fitness_score
```

### Using Conda Environment (Alternative)

Alternatively, if you prefer to use pip, you can install the requirements using the [`requirements_conda.txt`](env/requirements_conda.txt) file:
```bash
conda create --name Fitness_score --file requirements_conda.txt
```
### Using pip

Alternatively, if you prefer to use pip, you can install the requirements using the [`requirements_pip.txt`](env/requirements_pip.txt) file:
```bash
python -m venv venv
source venv/bin/activate  # On Windows use `venv\Scripts\activate`
pip install -r requirements.txt
```

## Usage

Adjust the scoring parameters in [`Fitness_score/data/input/Scoring_parameters.txt`](data/input/Scoring_parameters.txt) to suit your needs. The parameters include:

### Atom Type Configuration

- **Custom**: This option uses a homemade conversion table to categorize the standard 119 pdb atom types into the following simplified set of 11 custom atom types. 

| Element Name |                        Included Atoms/Residue Names                         |                                                       Description                                                       |
|:------------:|:---------------------------------------------------------------------------:|:-----------------------------------------------------------------------------------------------------------------------:|
|      H       |                              Any hydrogen atom                              |                           All hydrogen atoms regardless of their location or bonding context.                           |
|     Car      |    C in aromatic rings, ARG (CZ), GLN (CD), GLU (CD), ASP (CG), ASN (CG)    |                                      Aromatic and certain side chain carbon atoms.                                      |
|     Nbas     |              N in ARG (NH1, NH2, NE), HIS (NE2, ND1), LYS (NZ)              |            Nitrogen atoms with basic properties, often involved in hydrogen bonding and ionic interactions.             |
|     Nam      |  N in amide groups of ASN (ND2), GLN (NE2), TRP (NE1), peptide main chain   |         Nitrogen atoms in the amide groups of ASN and GLN, peptide main chain, and the indole nitrogen of TRP.          |
|      Oh      |            O in hydroxyl groups of SER (OG), THR (OG1), TYR (OH)            |                           Oxygen atoms in hydroxyl groups, capable of forming hydrogen bonds.                           |
|      Oc      |      O in carbonyl groups of ASN (OD1), GLN (OE1), peptide main chain       | Oxygen atoms in carbonyl groups, typically involved in hydrogen bonding, including those in the main chain of peptides. |
|     Oox      | O in carboxylate groups of ASP (OD1, OD2), GLU (OE1, OE2), C-terminus (OXT) |               Oxygen atoms typically seen in carboxylate groups or at the C-terminus of a protein chain.                |
|     Xot      |                   Atoms not fitting predefined categories                   | Atoms that do not match any other specified category, including various aliphatic carbons, sulfur, and uncommon atoms.  |
|     Oow      |                          Water molecule 'HOH' (O)                           |                Oxygen atoms in water molecules, important for hydration and protein structure stability.                |
|     Meta     |                       Metal atoms (e.g., FE, MG, CA)                        |                  Metal ions that can act as cofactors or structural elements within protein complexes.                  |
|    Hetatm    |                   Atoms from ligands or other heteroatoms                   |         Atoms from non-standard residues or ligands that are not covered by the standard amino acid categories.         |
|    Empty     |                                  None (-)                                   |      Placeholder for an environment that has fewer neighbors than the specified size; used to maintain uniformity.      |


- **Sybyl**: When selected, pdb atom types are mapped to 87 sybyl atom types using the Open Babel package. This choice is recommended for analyses that require the detailed atom type distinctions provided by the sybyl classification including heteroatoms and metal ions.

The sybyl atom type set includes two additional types:

  - `O.3.wat`: This type is designated for the oxygen atom in water molecules, crucial for analyses involving hydration effects.
  - `elt_symbol`: This is a general category for atoms identified by their elemental symbols, used for creating density distributions in cases where specific atom types lack sufficient training data.

### Other Parameters

Ensure you also set the other parameters in `Scoring_parameters.txt` to align with your project's goals. These include file 
paths for input and output, the inclusion of water in the environment, the environment size, and specific pocket and model configurations. 

### Running the Script

To run the script, navigate to the src directory, activate the environment if not already active, and execute [`Scoring_website.py`](src/Scoring_website.py) as follows:

```bash
cd src
conda activate Fitness_score
python Scoring_website.py
```

Protein structures to be scored should be placed in the [`Fitness_score/data/input/structures`](data/input/structures) directory and must be in `.pdb` format.

## Output

The script generates its output in the [`Fitness_score/data/output`](data/output) directory, with folders named by the date and time of the run. The output includes:
- [`detail_score`](data/output/2024-03-11_14-45-09/detail_score_sybyl): CSV files detailing the atomic fitness score  and molecular contact preferences for each atom. 
  ![Structure of the CSV_file](data/output/2024-03-11_14-45-09/detail_score_sybyl/github_csv.png)
- [`pdb_color`](data/output/2024-03-11_14-45-09/pdb_color_sybyl): PDB files with atomic fitness scores annotated in the b-factor column.
![Structure of the output PDB file](data/output/2024-03-11_14-45-09/pdb_color_sybyl/pdb_output.png)
- [`pdb_session`](data/output/2024-03-11_14-45-09/pdb_session_sybyl): PyMOL sessions with proteins colored by atomic 
fitness score and molecular contact preferences illustrated with CGO arrows. 
![Visual_of_the_Pymol_Session](data/output/2024-03-11_14-45-09/pdb_session_sybyl/Pymol_session.png)

  The PyMOL session is categorized into four groups: `Fitness_score`, `Contact_low`, `Contact_mid`, and `Contact_high`.
  The `Fitness_score` group displays the protein with a gradient coloring that reflects atomic fitness scores, transitioning
  from red for low fitness through green for neutral/middle fitness, to blue for high fitness.

  Contact preferences are indicated within the three other groups:

  - `Contact_low`: Contacts with a low frequency ratio (F<sub>obs</sub>/F<sub>exp</sub> < 0.5) in the training set are colored red.
  - `Contact_mid`: Contacts with a medium frequency ratio (0.5 ≤ F<sub>obs</sub>/F<sub>exp</sub> < 1.5) in the training set are colored green.
  - `Contact_high`: Contacts with a high frequency ratio (F<sub>obs</sub>/F<sub>exp</sub> ≥ 1.5) in the training set are colored blue.

  Each group contains four types of visualization objects:

  - The protein structure.
  - `Fobs_Fexp` objects, represented by dashed lines between contacting atoms.
  - `Dir` objects, shown as CGO arrows to indicate the direction of contact.
  - `Label` objects to display the frequency ratio (F<sub>obs</sub>/F<sub>exp</sub>).

  For simplification and flexibility, the latter three visualization types are categorized by their ranks of the contacts they represent and by whether they involve main chain or side chain contacts.

  ![List of PyMOL session Objects](data/output/2024-03-11_14-45-09/pdb_session_sybyl/pymol_session_screenshot_2.png)



## Reference data

The density distribution and contact frequency data used in this project are derived from a training dataset of protein structures called PDB30.
PDB30 is a subset of the structures in [the Protein Data Bank (PDB)](https://www.rcsb.org/) that aim to represent the diversity of protein structures in the PDB and minimize redundancy.
This dataset is based on [this file](https://cdn.rcsb.org/resources/sequence/clusters/clusters-by-entity-30.txt) available on the RCSB website,
where all PDB entries larger than 20 amino acids and sharing over 30% of sequences similarity have been clustered together
using [MMseq2](https://www.rcsb.org/docs/programmatic-access/file-download-services). The version of the clustering used in this project was downloaded the 19/01/2018 with 27 330 clusters.
From each cluster, the structure with the highest resolution determined by X-ray crystallography was chosen as the representative for a total of 22,930 structures with a mean resolution of 2.27 Å and a standard deviation of 0.66 Å.
 

The reference data are located within the [`Fitness_score/data/`](data) directory, categorized into:
- [`densities`](data/densities): Density distribution data for each atom type.
- [`frequencies`](data/frequencies): Contact frequency data for each atom type.
